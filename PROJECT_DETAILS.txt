1. EXECUTIVE SUMMARY & WHAT THE PROJECT IS ABOUT
--------------------------------------------------------------------------------
DeutschMaster is a comprehensive, production-grade web application engineered to
facilitate structured German language acquisition aligned with the Common European
Framework of Reference for Languages (CEFR, Levels A1–A2 and beyond).

The core objective of the platform is to solve key friction points in language
learning—specifically noun gender mastery (der, die, das), case declensions,
vocabulary retention, and exam readiness—through interactive, gamified software
modules and immediate pedagogical feedback.

Key Functional Modules:
  • Interactive Curriculum & Lessons: Structured topical lessons covering
    core grammar units (greetings, sentence structure, modal verbs, accusative
    and dative cases, prepositions, tenses) with step-by-step theory, practical
    dialogues, and knowledge-check quizzes.
  • Spaced-Repetition Flashcard Engine: A high-performance flashcard system
    supporting custom session limits (3, 5, 7, 10, 15, 20, or unlimited cards),
    article/gender color-coded training, category filters, and mastery tracking.
  • Comprehensive Exam Simulation Suite: Realistic simulation of standardized
    German examinations (Goethe-Zertifikat and telc format) covering four
    distinct testing modules:
      - Reading Comprehension (Lesen): Contextual texts with multi-choice
        and true/false verification.
      - Listening Comprehension (Hören): Synthesized audio prompts with
        comprehension verification.
      - Writing Assessment (Schreiben): Formal/informal letter and message
        composition with analytical rubric evaluation and sample solutions.
      - Speaking Assessment (Sprechen): Structured conversational scenarios
        with pronunciation, vocabulary, and grammar evaluation.
  • Practice & Drill Arena: Targeted exercises focusing on high-difficulty
    grammatical concepts, such as noun articles, verb conjugations, and sentence
    reordering.
  • Progress Tracking & Analytics: Comprehensive metrics dashboard tracking
    completed lessons, module-by-module exam scores, active study streaks,
    flashcard mastery points, and historical performance.
  • Community Contribution Pipeline: Content submission interface enabling
    learners and educators to propose new vocabulary, grammar examples, and
    exercises with administrative moderation status tracking.
  • User Management & Secure Persistence: Cloud-synced user profiles with
    guest-mode fallback, supporting cross-device synchronization and data security.


2. PLATFORM & DEVELOPMENT ENVIRONMENT
--------------------------------------------------------------------------------
Development & Execution Platform:
  • Runtime Environment: Node.js (v20+ / v22+) execution engine with modern
    ECMAScript Modules (ESM) architecture.
  • Package Management: npm / modern lockfile dependency resolution ensuring
    deterministic, reproducible builds.
  • Build System: Vite 6.x (Next-generation frontend tooling leveraging native
    browser ES modules for instant hot module reloading and optimized Rollup
    production bundling).
  • Language & Compiler: TypeScript 5.8+ configured with strict type-checking
    (`strict: true`, `noImplicitAny: true`, type-safe JSX transform).
  • Target Deployment Platform: Modern web browsers (Chromium, Firefox, Safari,
    Edge) running as a high-performance Single Page Application (SPA), fully
    responsive across mobile, tablet, and desktop viewports.


3. TECHNOLOGY STACK & ARCHITECTURE
--------------------------------------------------------------------------------
A. Frontend Core & Framework:
  • React 19: Built using modern functional component architecture, custom hooks,
    unidirectional data flow, optimized memoization (`useMemo`, `useCallback`),
    and granular state management.
  • TypeScript: End-to-end static typing across all data layers, including strict
    interfaces for lessons, exam sessions, flashcard items, quiz definitions,
    and user telemetry models.

B. Styling, Design System & UI Engineering:
  • Tailwind CSS v4: Modern utility-first CSS engine using direct engine imports,
    CSS variables, dynamic dark/light theme switching, and responsive design
    utilities.
  • Motion (formerly Framer Motion): Physics-based spring animations for card
    flips, smooth tab transitions, modal overlays, progress indicators, and
    celebratory visual cues.
  • Lucide React: Cohesive, scalable vector icon set integrated throughout
    navigation, status indicators, and operational controls.

C. Backend & Cloud Infrastructure:
  • Cloud Database: Google Cloud Firestore (NoSQL document-oriented distributed
    database) providing real-time data synchronization, low-latency document
    retrieval, offline persistence caching, and structured collections.
  • Authentication: Firebase Authentication handling identity management,
    secure credential hashing, JWT token verification, and session state.
  • Security & Access Control: Cloud Firestore Security Rules enforcing
    role-based access control (RBAC), user-level data segregation, and verified
    administrative permissions.
  • Offline-First Architecture: Hybrid data management utilizing browser
    LocalStorage for seamless guest operations, automatically synchronizing and
    merging with Firestore upon authenticated sign-in.

D. Native Browser APIs & Audio Engineering:
  • Web Speech API (SpeechSynthesis): Direct browser integration utilizing native
    German language speech synthesis engines (`de-DE` locale), with custom rate,
    pitch, and voice-selection controls for authentic German pronunciation.
  • Web Audio API (AudioContext): Custom-engineered programmatic sound synthesizer
    generating non-blocking, multi-frequency acoustic feedback (chimes, clicks,
    and tones) without requiring external audio asset downloads.


4. CORE SOFTWARE ENGINEERING HIGHLIGHTS & ARCHITECTURAL PATTERNS
--------------------------------------------------------------------------------
  1. Modular Domain-Driven Architecture:
     - Clear segregation of concerns: UI components (`/components`), domain
       types (`types.ts`), application constants and curricular content
       (`constants.tsx`), centralized service layer (`/services`), and cloud
       client configuration (`firebase.ts`).
  2. Custom State Orchestration:
     - Robust multi-screen routing and modal state management without heavy
       router bloat, ensuring instant transitions and state retention between
       tabs (Dashboard, Lessons, Flashcards, Practice, Exams, Contribution).
  3. Spaced-Repetition & Session Management Algorithm:
     - Dynamic deck queueing that prioritizes unmastered words, tracks session
       limits, calculates accuracy percentages, and records daily streak metrics.
  4. Assessment & Rubric Scoring Engine:
     - Granular scoring algorithms for multi-part exams, evaluating performance
       across CEFR competencies, calculating weighted percentages, and persisting
       modular score breakdowns.
  5. Responsive & Accessible Interface:
     - Mobile-first layout system with collapsible navigation, touch-friendly
       tap targets, high contrast dark/light themes, and semantic HTML elements.
  6. Zero-Dependency Audio Pipeline:
     - Utilization of native browser audio synthesis to eliminate external asset
       latency, reduce bundle payload, and enable offline sound capabilities.
